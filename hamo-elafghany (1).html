How to Publish This Website

3 free ways to get your site live on the internet in minutes.

1
Netlify — Easiest
Drag & Drop Deploy
  • Go to netlify.com/drop
  • Drag your HTML file into the page
  • Your site goes live instantly
  • Free .netlify.app URL given
  • Add custom domain in Settings
✓ 100% Free
2
GitHub Pages
Via GitHub Repo
  • Create account at github.com
  • Create new repository
  • Upload file as index.html
  • Settings → Pages → Deploy from branch
  • URL: username.github.io/repo
✓ 100% Free
3
Custom Domain
Your Own .com Domain
  • Buy domain at Namecheap.com (~$10/yr)
  • Deploy on Netlify (Step 1)
  • Netlify → Domain Settings → Add domain
  • Update DNS records at registrar
  • Wait up to 24 hrs — you're live!
~$10/year
